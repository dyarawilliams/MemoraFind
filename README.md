# MemoraFind

## Introduction
Welcome to MemoraFind — your gateway to preserving and exploring the rich history of Bamberg County’s resting places. With a sleek, intuitive interface and powerful search capabilities, MemoraFind makes it effortless to:

- Discover Loved Ones by name, plot number, or cemetery

- Access Detailed Records including burial dates, plot descriptions, and historical notes

- Navigate Seamlessly on any device, whether you’re at home or on the go

Designed for genealogists, historians, and families alike, MemoraFind brings every cemetery in Bamberg County to your fingertips. Uncover stories, honor memories, and share lasting legacies with just a few clicks. Start your journey today — because every name deserves to be remembered.

## About the Project

<a href="https://memorafind.netlify.app" target="_blank"> Live Demo </a>
<hr>

Memora Find is a community-focused web application dedicated to helping individuals locate and learn more about their loved ones buried in cemeteries across Bamberg County, South Carolina.

🔍 Core Features:
Advanced Search Filters: Find burial records by First Name, Middle Name, Maiden Name, Last Name, Birth Date, or Death Date.

Secure Record Updates: Users can request updates to a record, but changes require an admin-provided password to ensure accuracy and data protection.

💡 Motivation:
This project was inspired by the need for a centralized, easy-to-use tool that helps families stay connected to their heritage. Whether you're tracing your family tree or simply honoring a loved one, MemoraFind exists to make those moments easier and more meaningful.

More features and enhancements are on the way — because every memory matters.
